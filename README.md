# focus-ecg

**focus-ecg** es una aplicación diseñada para facilitar la interpretación automatizada de imágenes de electrocardiogramas (ECG). Permite cargar imágenes de ECG, procesarlas mediante técnicas de visión por computadora y aprendizaje automático, y obtener análisis preliminares sobre las características cardíacas presentes.

Esta herramienta está orientada a estudiantes, profesionales de la salud y desarrolladores interesados en la digitalización y análisis inteligente de registros ECG en formato imagen.

## Características principales

- Carga y preprocesamiento de imágenes de ECG en varios formatos (JPG, PNG, etc.).
- Extracción automática de señales y parámetros a partir de la imagen.
- Interpretación asistida mediante modelos de machine learning.
- Visualización clara de resultados y segmentos de interés.
- Interfaz gráfica intuitiva.

## Ejemplo de uso

1. Sube una imagen escaneada o fotografiada de un ECG.
2. La app procesa la imagen y extrae las señales relevantes.
3. Se muestran los resultados del análisis, como frecuencia cardíaca, detección de arritmias u otros parámetros.
